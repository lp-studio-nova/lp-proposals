3 LP制作の進め方

  1. ヒアリング

    サービス内容、ターゲット、LPの目的を確認します。

  2. 構成設計

    LPの成果を意識したセクション構成を設計します。

  3. デザイン

    ターゲットに合わせた視認性の高いデザインを制作します。

  4. コーディング

    HTML / CSSで軽量で高速なLPを制作します。

  5. 修正対応

    公開前に細かな調整や修正を行います。

  6. 納品

    HTML一式またはサーバーアップロードで納品可能です。
